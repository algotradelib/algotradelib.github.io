Detailed Description

template<typename Broker>
class algotradelib::runner::OrderUpdateWatch< Broker >

Turns successive working-order listings into order updates: the rows that changed since the previous listing.

Runner feeds each update to on_order_update; a live loop and a backtest both use it.

What a caller is told: what the broker last stated about an order it still lists. An order that leaves the listing produces nothing, because the listing does not say whether it filled, was cancelled, expired or was rejected. Whether a listing can show a terminal status at all is BrokerCaps::working_orders_state_terminal (false for every shipped broker).

A change is a difference in status_, execution_.filled_quantity_, price_, trigger_price_, quantity_, order_amount_ or canceled_at_, compared as numbers whatever their decimal scale. Identity fields and fill money (average price, amounts, fees, fill time) are not compared; read them off the row. A new row is reported; two UNKNOWN statuses in a row are not a change.

Rows are matched by OrderRef (both parts). A row with an empty reference is counted in untracked_rows() and never reported; a runner's reservation row (WorkingOrder::reserved_) is skipped.

Note
In a live loop the update arrives during the working-order poll, before that iteration's holdings read, so a TargetPosition stated in on_order_update is withheld as PORTFOLIO_SUPERSEDED and planned after the holdings read; an OrderIntent stated there is dropped.

template<typename Broker>
std::vector< OrderSnapshot > algotradelib::runner::OrderUpdateWatch< Broker >::changed ( const std::vector< WorkingOrder< Broker > > & rows)
inline

Compares a listing with the previous one and returns the rows that changed.

A row not seen before is returned. Rows missing from rows are forgotten, so an order that leaves and returns is reported again as new. An order listed twice with disagreeing readings is not reported and is counted in contradicted_rows().

Parameters
rowsThe complete listing, every page; a partial listing makes orders appear and disappear. The shipped adapters return complete listings.
Returns
The changed rows' snapshots.
