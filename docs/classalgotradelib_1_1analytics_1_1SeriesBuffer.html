Detailed Description

The most recent observations of a few fields, for a strategy fed one bar at a time.

Holds up to capacity() observations. Until it is full, each push adds one; after that, each push also drops the oldest. Check full() before computing an indicator whose window is the capacity, so it is never computed from fewer observations than its window.

column() returns the trailing values of one field, oldest first, as one contiguous view of the buffer's own storage. Storage is allocated once at construction and never grows. The trailing statistics themselves are the rolling_* functions in rolling.hpp.

Note
Not thread-safe: use one buffer from one strategy (one strand).
