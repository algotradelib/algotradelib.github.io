Detailed Description

An order to place, in broker-neutral form.

price_ must be set exactly when carries_caller_price(type_), and trigger_price_ exactly for STOP_LIMIT. An UNKNOWN type, time in force or session, or a combination the broker does not offer at the requested venue, is refused before any I/O.

◆ venue_

Venue algotradelib::OrderRequest::venue_ {Venue::UNSPECIFIED}

Where to route the order, if the broker offers a choice.

Set routing here, not in instrument_.venue_ (an adapter refuses an identity venue other than the one it reports). UNSPECIFIED takes the broker's default:

  • KIS routes UNSPECIFIED to KRX; COMBINED is sent as SOR on a real account, and on a demo account COMBINED and NXT are refused before any request (venue_unavailable);
  • Kiwoom requires a venue and refuses UNSPECIFIED before any request;
  • Toss offers no choice and refuses any venue but UNSPECIFIED.

A live runner sets it from live::SessionExecutor::default_route.
