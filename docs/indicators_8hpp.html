Detailed Description

Named technical indicators: z-score, Bollinger bands, RSI, ATR, MACD, and trailing covariance, correlation and beta.

They follow the conventions of rolling.hpp: the result is as long as the input, a value that cannot be computed is missing(), and nothing is reported before the window holds enough observations. Where an indicator has a conventional parameterization (Wilder's smoothing for RSI and ATR, spans for MACD), its documentation says which one it follows.
