Detailed Description

The library's version macros.

The version is <major>.<minor>.<patch>.<dev>: a dev part other than 0 means unreleased work after that release (0.0.0.9000 is the development version before any release). CMake reads its package version from this header, so the two always agree, and a build without CMake still has the macros.

#include <algotradelib/version>
#if ATL_VERSION >= ATL_VERSION_ENCODE(0, 1, 0)
// something 0.1.0 added
#endif
