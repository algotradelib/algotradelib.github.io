Detailed Description

The price grid (tick sizes) an instrument's order prices must sit on.

A broker states at most the tick at one price, not the ladder, so the library maintains these tables (source_ names the table and its revision); replace a rule if the exchange revises its grid. A rule of kind UNKNOWN refuses to check or round a price. A custom table needs positive ticks and bands sorted by from_.

std::optional< Decimal64 > algotradelib::PriceRule::round_to_tick ( const Decimal64 & price,
OrderSide side ) const
inline

Rounds a price to its band's tick in the order's favour: a buy rounds down, a sell up.

The tick is the one at price; a rounded price that crosses into the next band is not re-rounded. That is correct for the KRX table; with a custom table whose band boundaries are not multiples of both ticks, check the result with on_tick.

Parameters
priceThe price.
sideThe side of the order.
Returns
The rounded price (unchanged if already on the grid or there is no band at price), or std::nullopt if the grid is unknown or the arithmetic does not fit.
