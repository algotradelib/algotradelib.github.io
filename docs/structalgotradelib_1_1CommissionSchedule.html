Detailed Description

The commission rates a broker published for an account, or a caller stated.

An empty schedule from a broker that publishes rates is a real answer: the account has none.

RateSelection algotradelib::CommissionSchedule::rate_for ( Country country,
const VenueKey & asserted,
const Date & date ) const
inline

Finds the rate in force for a market and venue on a date.

First the rows keyed to asserted's venue are searched, then the venue-neutral ones; within each pass the first applicable row wins. If a row reached before any match has an unreadable window, the search stops and reports bounds_unreadable_. Asking with VenueKey::any() reads neutral rows only, so a schedule with only KRX and NXT rows answers nothing.

Parameters
countryThe market.
assertedThe venue the fill happened at, or VenueKey::any().
dateThe trading date.
Returns
The rate, or none with bounds_unreadable_ saying whether damage is why.

◆ tariff_

std::string algotradelib::CommissionSchedule::tariff_

Which tariff the rates are, in the source's own words.

Required for a caller-stated schedule: a backtest's cost model refuses one without it, because fee pages differ by account channel (온라인 영업점 개설 계좌, 온라인 뱅키스 계좌, 영업점매매), which no API states. A broker-published schedule carries the broker's own name.

How many rows have a date bound that could not be read.
