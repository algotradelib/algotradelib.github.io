Detailed Description

How small a difference from a target is not worth an order.

Every floor is optional and absent by default, which trades every share of drift. If any stated floor is met, no order is sent:

Floor Compares Use it for
minimum_quantity_ the drift in shares lot economics, a per-share fee
minimum_notional_ the drift's value at the reference price a fixed or minimum fee per order
minimum_fraction_of_working_ the drift over the quantity already working not giving up queue priority

A floor that cannot be evaluated (a notional floor without a price) does not suppress. A drift is never suppressed when an order on the wrong side has to be cancelled.
