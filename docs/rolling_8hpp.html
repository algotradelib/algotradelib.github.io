Detailed Description

Trailing-window statistics: means, deviations, extremes and moving averages.

Every series function returns a series as long as its input: row i of the result describes the window ending at row i of the input. A row that cannot be computed is missing().

Two numbers describe a window:

  • window is how many trailing rows are looked at, whether or not they carry a value;
  • min_observed is how many of those rows must carry a value before a result is reported.

Unobserved values inside a window are skipped, and the statistic is computed over the values that are there. rolling_mean(closes, 20, 15) reports as soon as 15 of the 20 rows are observed. The overloads without min_observed require every row of the window.
