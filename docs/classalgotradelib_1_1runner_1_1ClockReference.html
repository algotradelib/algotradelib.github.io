Detailed Description

template<typename Clock>
class algotradelib::runner::ClockReference< Clock >

A clock that reads another one, so that two holders (a loop and its journal) read one time.

Clocks are taken by value, and a copy of a ManualClock does not follow the original: a journal given one copy and a loop given another would stamp lines at the starting time while the loop moves on. Give both a ClockReference to the same clock instead.

Template Parameters
ClockThe clock read; it must outlive every copy of the reference.
