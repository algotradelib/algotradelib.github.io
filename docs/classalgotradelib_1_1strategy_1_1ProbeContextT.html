Detailed Description

template<typename CapsType>
class algotradelib::strategy::ProbeContextT< CapsType >

A context for testing a strategy without a runner: it records what the strategy asks for.

Set the public fields (now_, phase_, calendar_, portfolio_, instruments_), call a handler, then read submitted(), targets(), canceled() and log().lines(). ATL_ASSERT_STRATEGY(S, MinimalContext) compiles a strategy's handlers against it.

It has no series accessors (bars, frame, panel), so it needs no linear algebra backend; a strategy that reads series is checked by the runner it is bound to.

Template Parameters
CapsTypeThe broker capabilities the strategy sees as Ctx::caps; see NoCaps and AllCaps.
