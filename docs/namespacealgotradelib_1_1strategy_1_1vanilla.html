◆ AverageKind

enum class algotradelib::strategy::vanilla::AverageKind
strong

Which moving average MovingAverageCrossover uses.

  • SIMPLE reads the last slow_ + 1 closes.
  • EXPONENTIAL reads every cached close (up to the runner's series_capacity). A line with at least three spans of observed closes uses analytics::ema seeded at the oldest close; a line with fewer uses adjusted_ema, which does not overweight the first close (right for a new listing). The choice is made per line.
Note
With EXPONENTIAL, the signal can change on an unchanged close when one line switches from the adjusted to the plain average. A span above a third of series_capacity (170 at the default 512) always uses the adjusted average. A backtest, whose cache keeps growing, can differ from a live run that loaded fewer bars until the live cache catches up.
Enumerator
SIMPLE 

The simple mean of the window.

EXPONENTIAL 

An exponential average with alpha = 2 / (span + 1), over every cached bar.

math::Vector algotradelib::strategy::vanilla::adjusted_ema ( math::SeriesView values,
math::Scalar alpha,
std::size_t min_observed = 1 )
inline

Computes the bias-adjusted exponential moving average.

At each row, the exponentially weighted mean of the observations so far, with weights 1, q, q^2, ... (newest first, q = 1 - alpha) normalized to sum to one. On finite observed rows it equals pandas' ewm(alpha=alpha, adjust=True, ignore_na=True).mean(). Unlike analytics::ema, the first observation never weighs more than its exponential share, so use it on a short series with no history before its first row. A finite constant series gives exactly that constant.

Warning
An infinity counts as an observation: the average becomes infinite, then NaN from the next finite value on, for the rest of the series (except at alpha = 1, which keeps only the newest value).
Parameters
valuesThe series; NaN entries are skipped and their rows left missing().
alphaThe smoothing factor, in (0, 1].
min_observedHow many observations must be seen before a value is reported.
Returns
The averages, one per row.
Exceptions
std::invalid_argumentunless 0 < alpha <= 1, or if min_observed is zero.

Returns the last count + 1 rows of a series.

Slice before computing a windowed indicator when only its latest values are needed, so the cost per bar does not grow with the cached history. Not for a recursive indicator such as an EMA, whose value depends on every earlier row.

Parameters

countThe indicator's window; one more row is kept for the previous value.
Returns
A view of the last count + 1 rows, or std::nullopt if there are fewer.
