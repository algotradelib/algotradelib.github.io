Detailed Description

Positions, cash and realized profit, updated by each execution of a replay.

Cash and profit are kept per currency and never converted.

Applies one execution to the position, cash and realized profit.

A trade through flat (selling 150 from a long of 100) closes the old position, realizing its profit against the old average, and opens the remainder at the new price. Commission, institution fee and tax are deducted from cash.

Parameters
execution_inThe execution; it may be one of executions(). Kept (copied) only with ExecutionHistory::KEEP.
currency_inThe instrument's currency.
Returns
false, with the ledger unchanged, if the arithmetic does not fit, or if currency_in differs from the currency of a non-flat position in the instrument; true otherwise.
Exceptions
std::bad_allocIf an allocation fails; the ledger is then unchanged.

◆ equity()

std::optional< Decimal64 > algotradelib::backtest::ReplayLedger::equity ( ) const
inline

Returns total equity in the ledger's own currency (the constructor's), as equity_in would.

The same value, digit for digit and in the same representation, as equity_in for that currency, without adding up every position: the ledger keeps a running total. It uses it only while the magnitudes of the cash and of every position it counts, added up and written at the largest scale among them, fit – which guarantees that equity_in's own additions, in any order, cannot overflow – and otherwise calls equity_in.

Returns
The equity, or std::nullopt if the arithmetic does not fit.

Returns the portfolio a strategy sees.

The model a replay presents: every held share is sellable (basis whole holding, deduct resting sells, unverified), buying power is this ledger's cash (no settlement is modelled), and cash_ is filled. Working orders are left empty; Backtester fills them from its queue.

◆ update()

template<typename BrokerTag>
void algotradelib::backtest::ReplayLedger::update ( strategy::Portfolio< BrokerTag > & portfolio,
std::chrono::system_clock::time_point as_of )
inline

Brings a portfolio built by snapshot up to date, changing only what changed since.

Afterwards its positions, sellable basis, cash, buying power and as_of_ are what snapshot would return now; its working orders and everything else are left alone. Only the lots that apply or mark changed since snapshot, clear_changed or the last update are rewritten, plus any opened since, so a bar that marked one lot rewrites one row.

The portfolio must be one this ledger's snapshot built, whose positions only update has changed since; anything else written to them stays.

Template Parameters
BrokerTagThe order-reference tag of the portfolio.
Parameters
portfolioThe portfolio to update.
as_ofThe time, for as_of_ and the buying-power stamps.
Exceptions
std::bad_allocIf a row, the cash or the buying power cannot be copied; the ledger still lists every changed lot, so a later update completes it.
