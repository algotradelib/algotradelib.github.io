Detailed Description

Holds an equal fraction of portfolio value in each instrument of a universe.

Rebalances only when the market enters rebalance_at_ (via on_phase), not on every bar. Each weight is 1 / n truncated at weight_scale_ decimal places (three names get 0.3333); the residual stays unallocated. Each weight is a holding (SizeSpec::target_weight), so a rebalance trades only the drift; set a notional TradeTolerance to skip one-share drifts.

Note
Live, the runner refuses weights (no_portfolio_value) until you call Runner::set_portfolio_value.
In a backtest on daily bars, on_phase fires about once in the whole run, because the replay clock visits only bar ends; replay intraday bars to rebalance each session. In a multi-instrument replay the other instruments are sized at their previous close; on a mixed-currency replay the portfolio value counts one currency only; and quotes move prices while the value stays at the last bar's marks.
