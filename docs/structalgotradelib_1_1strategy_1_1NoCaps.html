Detailed Description

A capability set in which the broker implements nothing optional.

Inherit it in a test's capability set and override only what differs.

◆ working_orders_state_terminal

bool algotradelib::strategy::NoCaps::working_orders_state_terminal = false
staticconstexpr

Whether the working-order listing can show a terminal status (filled, cancelled, ...).

false for KIS, Toss and Kiwoom: their listings show only open orders. Then an order that leaves the listing has no terminal on_order_update; read its outcome from holdings or an order inquiry instead of waiting for one. false here when has_working_orders is false.
