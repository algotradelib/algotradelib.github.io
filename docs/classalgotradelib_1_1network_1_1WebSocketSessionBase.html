Detailed Description

template<typename Derived, typename Stream>
class algotradelib::network::WebSocketSessionBase< Derived, Stream >

The base of the WebSocket clients WsSession and WssSession: connecting, sending, receiving, closing and reconnecting.

To use a session, derive from WsSession or WssSession, override on_message (and optionally on_open, on_error, on_closed), create it with std::make_shared, and call connect(). All handlers run on the session's strand.

◆ abandon_if_closing()

template<typename Derived, typename Stream>
bool algotradelib::network::WebSocketSessionBase< Derived, Stream >::abandon_if_closing ( )
inlineprotected

Ends a connect that close() interrupted, if it did; called first by each connect stage that completed without an error.

close() cancels the stage in progress, but a stage whose completion was already queued arrives without an error. Going on would open a session whose close() is spent: on_closed would never be called, and a later close() would return early because one is in progress.

Returns
true if the session was closing: it is torn down and on_closed has been called.
