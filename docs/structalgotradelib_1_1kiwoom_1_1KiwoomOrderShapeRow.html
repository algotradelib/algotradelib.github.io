Detailed Description

One row of Kiwoom's order-type table: the numeric request code, the Korean names its listings report, and the normalized shape.

The unfilled and filled listings (ka10075 미체결, ka10076 체결) and history (kt00007, kt00009) name some shapes differently (보통 vs 지정가), hence two names. These are the documented names; a server may write another (the demo server's history says 보통가, which KiwoomClient reads on the demo only).
