Detailed Description

Placeholder types and the refusal used by DataOnlyTraits.

No value of the placeholder types is ever produced: every member that would produce one refuses.

template<typename Out, typename Handler>
void algotradelib::data_only::post_refusal ( Handler && handler)

Completes an asynchronous call with refusal(), posted through the handler's associated executor.

Never invoked inside the initiating call (though on a multi-threaded executor it may run before that call returns); the handler is moved once and called once, so it may be move-only. A handler bound to a strand completes on that strand.

Template Parameters
OutThe result type of the call.
HandlerThe completion handler type.
Parameters
handlerThe handler, called with Result<Out>(refusal()).
