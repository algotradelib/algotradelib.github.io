Detailed Description

The library: broker-neutral types (core), and the modules below.

Include <algotradelib/core> for orders, quotes, bars, instruments and the calendar, and <algotradelib/broker> for the broker port (BrokerSession, BlockingSession, BrokerTraits, BrokerCaps); each module has its own umbrella header (<algotradelib/runner>, <algotradelib/kis>, ...).

The execution condition is TimeInForce and the session is OrderSession; a broker's single order code (such as KIS ORD_DVSN) maps to all three.
