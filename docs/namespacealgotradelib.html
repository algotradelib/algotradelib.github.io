Detailed Description

The library: broker-neutral types (core), and the modules below.

Include <algotradelib/core> for orders, quotes, bars, instruments and the calendar, and <algotradelib/broker> for the broker port (BrokerSession, BlockingSession, BrokerTraits, BrokerCaps); each module has its own umbrella header (<algotradelib/runner>, <algotradelib/kis>, ...).

◆ BarStamp

enum class algotradelib::BarStamp
strong

Which edge of its period a bar's timestamp marks.

Brokers differ: Toss stamps a minute bar at its close (covering [t - 1m, t)) and a daily bar at local midnight, its open; KIS and Kiwoom stamp a minute bar at the start of its minute and a daily bar by its trading date, both opens. Reading an open-stamped bar as close-stamped looks ahead by one bar.

Enumerator

The timestamp is the first instant of the period.

CLOSE 

The timestamp is the instant the period ended.

◆ lists_every_value() [2/2]

template<typename Enum, std::size_t N, typename IsEnumerator>
bool algotradelib::lists_every_value ( const std::array< Enum, N > & values,
IsEnumerator is_enumerator )
constexprnoexcept

Tests whether a list holds every value of an enum exactly once, in any order.

The enum must be scoped (enum class), and its values 0 to N - 1: no enumerator may state its own value. Then N distinct enumerators below N are all of them, and N itself must not be one, or the enum is longer than the list (unless N values already fill the underlying type).

Use it in a static_assert beside the list. Pass a test that is true exactly for the enum's values, such as the enum's name function, whose switch has a case for each value and returns "" after it:

static_assert(lists_every_value(all_venues, [](Venue venue) { return !venue_name(venue).empty(); }));
