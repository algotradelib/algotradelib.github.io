Detailed Description

template<typename Broker>
class algotradelib::strategy::SellableConventionProbe< Broker >

Infers a broker's SellableConvention from successive portfolios.

Call observe with each polled portfolio. An observation is recorded only when, between two polls, an instrument's holding is unchanged, the resting sell quantity the broker reported grew, and the gap between held and sellable moved by exactly that amount (NET_OF_RESTING) or not at all (GROSS_OF_RESTING); anything else is discarded. Positions whose sellable basis is not enforceable, or which carry no sellable figure, are skipped, so with a broker that does not publish the figure the verdict stays UNDETERMINED.

Warning
Fed a backtest's portfolios, it learns the replay ledger's model (which reports sellable as held), not a broker's behaviour.
