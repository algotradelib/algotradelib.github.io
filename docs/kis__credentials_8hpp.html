Detailed Description

The examples' KIS credentials: one JSON file per account, or the environment.

Not part of the library. With a credentials directory – --credentials DIR on the command line, else ATL_CREDENTIALS_DIR – the examples read DIR/kis/demo.json or DIR/kis/real.json, as KIS_DEMO chooses (unset or 1: demo; 0: real). Without one they read the environment variables, as before. A directory that is given but lacks the file stops the program: it never falls back to the environment, which may hold the other account's keys.

Each file holds app_key, app_secret, account_number, account_product_code and demo (KisConfig::from_json, KisAccount::from_json). Keep it chmod 600.

Returns transport options that pace a KIS client at one request a second.

A KIS demo account refuses reads closer than about a second apart (EGW00201), and with real keys the holiday calendar was refused at eight a second. The library paces nothing unless asked (HttpClientOptions::rate_limit_), so these examples ask. A key with a larger allowance may raise it.

Returns
The options.
