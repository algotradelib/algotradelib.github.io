enum class algotradelib::kis::KisRateLimitLayer
strong

Which of KIS's two request-rate limits a refusal reports.

Enumerator
NONE 

Not a rate-limit refusal.

LEDGER 

An endpoint's own cap shared by all customers (EGW00215; 120 per second for holdings and ETF quotes). Your budget cannot avoid it; wait and retry.

PERSONAL 

This app key's own per-second limit (EGW00201); lower the budget.

◆ unsupported_client_order_id()

std::optional< BrokerError > algotradelib::kis::unsupported_client_order_id ( const OrderRequest & order)
inline

Refuses an idempotency key, which KIS does not offer to individual customers.

Without one, resending after a transport failure can place a second order, so an order carrying client_order_id_ is refused before sending rather than sent without it. confirm_high_value_ is accepted (and ignored).

Parameters
orderThe order.
Returns
An INVALID_ARGUMENT error (idempotency_key_unsupported, not sent) if the order has a client order id, otherwise std::nullopt.
