Detailed Description

template<typename BrokerTag, typename CapsType>
class algotradelib::runner::Context< BrokerTag, CapsType >

What a strategy's handlers receive as ctx: everything the strategy may read, and where it queues what it wants.

The same type in a dry run, a live session and a backtest. Nothing here performs I/O: every read comes from caches the runner filled, and submit and cancel only queue requests, which the runner checks and sends after the handler returns. The members under "What the runner uses" are for runners, not strategies.

Template Parameters
BrokerTagThe broker tag of order references (a strategy reads them with auto).
CapsTypeThe broker capabilities, exposed as caps for if constexpr.
