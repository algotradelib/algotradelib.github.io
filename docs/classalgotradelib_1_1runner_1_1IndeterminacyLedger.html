Detailed Description

The instruments with an order of unknown outcome, where nothing may be placed until the broker's order list is read and the instrument resolved.

Named cancellations are not blocked. Only resolve_after_reading_orders clears an entry; reading the list alone does not. The ledger is in memory: it does not survive the process, and an order in flight when a process is killed is never recorded. After an abnormal exit, read the broker's order list before trading; PollingLoop does this before its first send, and a FileJournal (live::bind_journaled) carries unresolved instructions across a restart for recover_runner.

Note
Killing a runner does not cancel orders the broker already accepted.
