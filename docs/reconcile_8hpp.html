Detailed Description

Reconciliation: turning a strategy's intents and targets into the orders and cancellations to send.

The reconcile functions are pure: no I/O and no state. A target is compared with the position plus the orders already working, so restating it does not order twice. A buy above the day's band is clamped down to it and a sell below it up (a less aggressive price is left as it is), prices are rounded onto the tick grid, and quantities rounded down onto the lot; each adjustment is flagged on the PlannedOrder.
