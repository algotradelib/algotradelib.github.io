Detailed Description

An asynchronous HTTP/1.1 client over TLS that keeps one connection to one host, used by the broker clients.

Requests are queued by priority (HttpRequest::group_, then arrival) and sent one at a time on a strand. Each completion runs on the handler's associated executor, or on the client's strand if it has none.

A GET that fails on the connection is sent once more; any other request never is. Before a request other than a GET is admitted, a connection idle longer than HttpClientOptions::unreplayed_idle_limit_ is replaced by a fresh one, once per request: if the request then waits for rate-limit admission longer than that limit, it is still written on the fresh connection. With a rate-limit budget, a request waits for admission, and fails with admission_deadline if the wait would exceed the timeout.

With HttpClientOptions::fresh_connection_for_orders_ on, an order (HttpRequest::group_ TRADING) is written only on a connection that no request has begun writing on. When it is admitted and the connection has been used, or has sat unused longer than unreplayed_idle_limit_ (once per request), the connection is replaced first and admission evaluated again, so such an order costs a TLS handshake.

A failed request's BrokerError::reached_broker_ is false only if no attempt at it began writing (a failure while resolving, connecting or handshaking, or a refusal in the queue). true means a write was begun, by this attempt or an earlier one (a retried GET), so the broker may have received it; it does not prove it did.

Create it with std::make_shared: it uses shared_from_this.

std::uint64_t algotradelib::network::AsyncHttpClient::admission_waits ( ) const
inlinenoexcept

Returns how many times the client started a rate-limit admission wait.

It counts waits started, not requests delayed (a request can wait more than once); for delayed requests read RateLimitStats::delayed_. Always zero for a client without a budget. Read it on the client's strand or after the event loop has stopped.

Returns
The count.
