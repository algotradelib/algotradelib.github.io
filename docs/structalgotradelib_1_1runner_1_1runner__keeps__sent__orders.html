Detailed Description

template<typename Runner, typename = void>
struct algotradelib::runner::runner_keeps_sent_orders< Runner, typename >

Detects Runner::keeps_sent_orders_until_listed.

true when undeclared: a runner that does not say is assumed to keep each order it sends until a working-order listing accounts for it, so PollingLoop holds it while that listing is missing. A type wrapping runner::Runner should forward the constant; one that keeps no sent orders declares it false.
