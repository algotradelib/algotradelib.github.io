◆ Alignment

enum class algotradelib::analytics::Alignment
strong

How Panel::from_bars lines up instruments whose bars fall on different instants.

There is no default: each choice changes what a cross-sectional statistic means.

Enumerator
UNION_UNOBSERVED 

Every instant any instrument reported; an instrument with no bar there is missing().

No value is invented; reductions see fewer observations for instruments that did not trade.

INTERSECTION 

Only the instants every instrument reported.

Gives complete rows for cross-sectional work (covariance, ranking, weights), but drops much data when one instrument's history is short.

FORWARD_FILL 

Every instant any instrument reported; a gap repeats the instrument's last value.

Rows before an instrument's first bar stay missing().

Warning
A carried value is stale: a return across a filled gap is zero, then jumps when trading resumes.

◆ ema() [1/2]

math::Vector algotradelib::analytics::ema ( math::SeriesView values,
Scalar alpha,
std::size_t min_observed = 1 )
inline

Computes the exponentially weighted moving average of a series.

The level is seeded with the first observed value and then updated as alpha * value + (1 - alpha) * level (the update ema_step makes). An unobserved value is skipped: the level carries over it and that row is missing(). On observed rows the result equals pandas.Series.ewm(alpha=alpha, adjust=False, ignore_na=True, min_periods=min_observed) .mean() up to rounding.

Parameters
valuesThe series; NaN entries are unobserved.
alphaThe smoothing factor, in (0, 1]; for a period, pass alpha_from_span(span).
min_observedHow many values must have been observed before a level is reported; raise it to hide the rows where the seed still dominates.
Returns
The levels, one per row.
Exceptions
std::invalid_argumentunless 0 < alpha <= 1, or if min_observed is zero (even for an empty series).
Warning
In a live loop, keep the level yourself with ema_step. Running ema over a trailing SeriesBuffer view reseeds from the oldest row each time and gives different levels.

inline

Converts a computed value into a price an order can carry.

The value is rounded to a decimal at scale in the order's favour (a buy down, a sell up), then onto the tick grid the same way, so a buy is never above the computed value (by more than floating-point noise) and a sell never below it: with the KRX grid and scale = 0, a buy at 1999.8 gives 1999 and a sell at 2000.2 gives 2005. A value within floating-point noise of a decimal counts as that decimal, so a market price converted from a Decimal64 comes back unchanged (a coefficient beyond 2^52 may not).

ruleThe instrument's tick rule.

Returns
The price, or std::nullopt if value is not finite (such as an indicator's warm-up missing()), does not fit a Decimal64, or rule has no grid (PriceRule::Kind::UNKNOWN).
