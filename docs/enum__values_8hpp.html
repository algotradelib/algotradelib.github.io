Detailed Description

A compile-time check that a list names every value of an enum, and a parser over the list.

The library keeps a list of every value next to several enums (all_venues, all_halt_reasons, ...) and derives counts, parsers and tests from it. Each list is checked with lists_every_value in a static_assert, so a value added to the enum and left out of its list fails to compile. value_named reads a name back through the same list.
