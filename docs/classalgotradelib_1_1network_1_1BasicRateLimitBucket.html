Detailed Description

template<typename Clock = std::chrono::steady_clock>
class algotradelib::network::BasicRateLimitBucket< Clock >

A rate limiter (the generic cell rate algorithm) that computes when a request may go; it neither waits nor reads the clock itself.

Each call passes the current instant and an allowance: how much of the burst the caller may use (see usable_burst). A caller with a smaller allowance reaches its limit earlier, so one schedule can keep a reserve for trading.
