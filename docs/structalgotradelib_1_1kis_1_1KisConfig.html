Detailed Description

KIS credentials (app key and secret), demo or real account, and the market-data tape.

Load with from_env() (KIS_APP_KEY, KIS_APP_SECRET, KIS_DEMO) or from_json(filename).

◆ is_demo_

bool algotradelib::kis::KisConfig::is_demo_ = true

Whether to use KIS's demo (모의투자) endpoints; true unless stated otherwise.

Real trading must be stated: KIS_DEMO=0, "demo": false in the credential file, or is_demo_ = false. Real-account keys sent to the demo endpoints are refused at the first token request, so a forgotten setting fails rather than trades.

MarketTape algotradelib::kis::KisConfig::market_tape_ = MarketTape::CONSOLIDATED

Which venue's prices every KIS market-data request reads (quotes, bars, depth, price bands, trades); KRX and NXT combined by default, as Toss reports.
