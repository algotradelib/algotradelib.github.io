Detailed Description

template<typename T>
class algotradelib::mock::DataFeed< T >

The mock vendor: records the caller gives, each released once the clock reaches the time it was published.

It is a data poll as runner::PollingLoop::set_data_poll takes one: on the mock market's clock (mock::MarketClock) one clock moves the market and the feed, and the loop stamps each record with the reading at which it received it.

mock::DataFeed<Record> feed({{published_at, record}, ...});
loop.set_data_poll(feed); // a copy; std::ref(feed) to keep reading `remaining()`
