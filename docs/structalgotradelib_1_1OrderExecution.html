Detailed Description

What has filled on one order, and what it cost.

Warning
Test whether an order filled with filled_quantity_, never with whether an amount is present: KIS reports a zero filled_amount_ on unfilled orders, and Toss leaves amounts empty when the broker sent null.

At Toss, an amount sent as null is empty, but a missing field fails the listing as a protocol error.

std::optional<Decimal64> algotradelib::OrderExecution::average_filled_price_

The average fill price, only where the broker supplies it.

KIS's real-server open-order listing never sets it, even on a partly filled order; on a demo account, where the listing is built from the day's history, it is set once something has filled.
