◆ message_

std::string algotradelib::BrokerError::message_

A human-readable description, for logs; do not parse it.

For an HTTP error from KIS or Kiwoom it carries the start of the reply's body (at most 512 bytes, then the count of bytes left out); that is an excerpt, not redaction. A broker's declared error carries its own message field. A whole successful reply the adapter cannot read is not copied (a token reply holds the token).

◆ reached_broker_

bool algotradelib::BrokerError::reached_broker_ {true}

Whether a request was sent before this error.

false when nothing was written: the client refused before any I/O (an order id too long, an unsupported time in force), or the transport failed before writing (resolving, connecting, handshaking, a full queue, or a closed client). Such an error is not counted against a rate limit and was not the broker's; a runner may offer the instruction again. Defaults to true.
