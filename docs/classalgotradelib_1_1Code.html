Detailed Description

template<std::size_t N>
class algotradelib::Code< N >

A short uppercase code (letters, digits, _), stored inline without allocation.

The length is stored in one byte, so N must be at most 255.

Holds a broker code the library may not recognize (a market segment, an exchange id) exactly as sent, so it can be carried, compared and displayed.
