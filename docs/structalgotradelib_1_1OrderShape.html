Detailed Description

An order's type, price, trigger, time in force and session, as an amendment states them.

In an amendment, an unset time in force or session keeps the order's own. An unset trigger keeps the resting trigger only when both the new and the resting type are STOP_LIMIT; turning a stop into a plain LIMIT drops its trigger. To change only the price, use reprice.

◆ trigger_price_

std::optional<Decimal64> algotradelib::OrderShape::trigger_price_

The trigger price, for STOP_LIMIT.

On an amendment, unset keeps the resting stop's trigger, but only when both the new and the resting shape are STOP_LIMIT (see amended_trigger_price); changing into a stop needs a trigger stated. A trigger set on a type that takes none is refused. On an OrderRequest, a stop-limit without one is refused.
