Detailed Description

template<typename Inner, typename Journal, typename Clock = SteadyClock>
class algotradelib::runner::JournalingExecutor< Inner, Journal, Clock >

An executor wrapper that records each instruction in a journal before sending it.

place and cancel append a PENDING line, call the wrapped executor only if the append succeeded, and append its outcome. The line is as durable as the journal makes it before append returns: FileJournal flushes it to disk, MemoryJournal (for tests and dry runs) loses it at exit. A journal of your own must write durably before returning success if it is to be recovered from after a crash. The wrapped executor's outcome is returned unchanged, except that if the PENDING line cannot be written, nothing is sent and the outcome is SendOutcome::UNAVAILABLE (which stops the runner). If only the answering line fails, the send has happened; the failure is recorded and the instruction will look unresolved to recovery. A backtest does not use it.

Template Parameters
InnerThe wrapped executor.
JournalThe journal type (MemoryJournal or FileJournal).

template<typename Inner, typename Journal, typename Clock = SteadyClock>
void algotradelib::runner::JournalingExecutor< Inner, Journal, Clock >::set_id_prefix ( std::string prefix)
inline

Sets the prefix of line ids.

Ids are the prefix, a hyphen and a counter starting at one (<prefix>-1), and recovery pairs lines by id, so the prefix must differ between every executor run that shares a journal. The default is the wall-clock construction time in microseconds (not the injected clock's), which is distinct only if no two executors on the journal are made at the same instant.
