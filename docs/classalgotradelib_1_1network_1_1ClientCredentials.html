Detailed Description

template<typename BrokerType>
class algotradelib::network::ClientCredentials< BrokerType >

OAuth client credentials (an app key and secret), the base of each broker's credentials class.

The broker class derives from it (CRTP) and provides from_env_impl(), from_json_impl(filename), and the static key_field() and secret_field() naming the token request's JSON fields.

BrokerTypeThe derived broker credentials class.
