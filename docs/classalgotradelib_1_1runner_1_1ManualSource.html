Detailed Description

template<typename Runner>
class algotradelib::runner::ManualSource< Runner >

A source for tests: each poll returns a queued or default outcome, without any network.

It installs a calendar only during PollKind::CALENDAR (see set_calendar), the rule every source must follow.
