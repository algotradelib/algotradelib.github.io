Detailed Description

An amendment or cancellation of a KIS order.

KIS re-sends the whole order shape (one ORD_DVSN code composed from type, condition and session, which differs by venue) on both, so state the order's type, condition, session and price as they should be after the amendment, and the venue where it rests, on a cancellation too: the same checks apply (a limit order needs a positive whole-won price; a market order must carry none). Read the amendable quantity first from async_open_orders (KisOpenOrder::amendable_quantity_). A demo account accepts only Venue::KRX (or UNSPECIFIED); others are refused before sending.

◆ trigger_price_

std::optional<Decimal64> algotradelib::kis::KisAmendment::trigger_price_

The trigger price (KIS's CNDT_PRIC), for a STOP_LIMIT order.

Required when amending a stop-limit order and refused for any other type. On a cancellation it is sent if valid and otherwise left off, so a cancellation is never refused for the trigger price (the other fields are still checked).
