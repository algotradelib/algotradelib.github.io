Detailed Description

template<typename BrokerType>
struct algotradelib::network::AuthBody< BrokerType >

An OAuth access token and its expiry, the base of each broker's token-response class.

The broker class derives from it (CRTP) and provides the static token_field() naming the token's JSON field, and from_json_impl(document) to read anything else (such as an absolute expiry).

Reads a token response.

Reads the token, a relative expires_in (a whole number, or a string of one) if present, then calls the broker's from_json_impl, which may set an absolute expiry.

Parameters
documentThe response.
Exceptions
std::runtime_errorif the token field is missing or not a string, or the response states no expiry (no lifetime is assumed); or whatever the broker's from_json_impl throws.
