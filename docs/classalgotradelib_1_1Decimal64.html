Detailed Description

An exact signed decimal: an int64 coefficient times 10^-scale.

Prices, quantities and money are Decimal64 wherever they come from or go to a broker. The arithmetic is the decimal_* free functions, which return std::nullopt when a coefficient, scale or intermediate value does not fit (a result whose final value would fit can still fail).

Compares the coefficient and the scale.

Values from parse and the decimal_* functions are normalized, so for them this compares the numbers. A value built with an explicit scale is not: Decimal64(150, 2) does not equal Decimal64(15, 1). To compare numbers at any scale, use decimal_less both ways or decimal_normalized first.

Parameters
lhsThe first value.
rhsThe second value.
Returns
true if coefficient and scale are both equal.
