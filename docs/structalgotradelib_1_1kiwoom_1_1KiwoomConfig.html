Detailed Description

Kiwoom credentials (app key and secret key), demo or real account, the market-data tape, and the holdings settings an account must state before trading.

Load with from_env() (KIWOOM_APP_KEY, KIWOOM_SECRET_KEY, KIWOOM_DEMO) or from_json(filename). Holdings cannot be read until holdings_venue_ is set. Orders cannot be placed or amended, and the session (so a runner) reads no holdings, until holdings_position_scope_ is set; a checked sell also needs holdings_sellable_scope_.

◆ holdings_position_scope_

KiwoomPositionScope algotradelib::kiwoom::KiwoomConfig::holdings_position_scope_ = KiwoomPositionScope::UNSPECIFIED

Your assertion of what holdings_venue_ means for the positions listed. No default: until it is set, every new order and amendment is refused and the session reads no holdings (cancellations, including cancel_quantity(), still go).

Kiwoom does not document it, and two reads cannot settle it (the account can change between them). A wrong assertion undercounts the account: a buy can pass a ceiling already reached, and a sell can be refused or sized too small.

◆ holdings_sellable_scope_

KiwoomSellableScope algotradelib::kiwoom::KiwoomConfig::holdings_sellable_scope_ = KiwoomSellableScope::UNSPECIFIED

Your assertion of what a holdings row's tradable quantity covers; separate from the position scope, since Kiwoom documents neither.

UNSPECIFIED (the default) leaves the sellable basis unestablished, so RiskGuard refuses a checked sell. WHOLE_HOLDING supplies the coverage; resting sells are deducted either way.

◆ holdings_venue_

Venue algotradelib::kiwoom::KiwoomConfig::holdings_venue_ = Venue::UNSPECIFIED

The venue holdings requests (kt00018) name: Venue::KRX or Venue::NXT. No default: holdings requests are refused until it is set..

kt00018 has no all-venue value, and the library does not request both and merge them: if the venue only selects the valuation price, merging would double every position. If instead it filters positions, one venue's request omits what is held on the other, so a position ceiling would see too little. Which it is, Kiwoom does not document; see holdings_position_scope_. Venue::COMBINED is refused.

◆ is_demo_

bool algotradelib::kiwoom::KiwoomConfig::is_demo_ = true

Whether to use Kiwoom's demo (모의투자) endpoints; true unless stated otherwise.

Real trading must be stated: KIWOOM_DEMO=0, "demo": false in the credential file, or is_demo_ = false. Real-account keys sent to the demo endpoints are refused at the first token request, so a forgotten setting fails rather than trades.
