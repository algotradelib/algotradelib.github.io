Detailed Description

template<typename Client>
class algotradelib::BrokerSession< Client >

An asynchronous broker client bound to one account, with broker-neutral operations.

Every operation takes a completion token and completes once with Result<T>, on the handler's associated executor. An operation the broker does not offer (see Caps) does not compile; gate it with if constexpr. A request the session or adapter refuses before any I/O completes with an error that is posted, never invoked inline. For a handler with no associated executor, that refusal runs on the system executor while a broker's reply runs on the client's strand, so one callback can run on two threads; bind the handler to an executor if that matters. A session is cheap to copy (a shared client pointer and the account).

Template Parameters
ClientAn asynchronous broker client (BrokerTraits<Client>::blocking is false); use BlockingSession for a blocking one.

◆ rate_limit_stats()

template<typename Client>
const network::RateLimitStats * algotradelib::BrokerSession< Client >::rate_limit_stats ( ) const
inline

Returns the client's request-pacing counters.

A rising delayed_ on a polling group while TRADING stays undelayed means trading capacity is being kept free; a rising shed_ means the queue was full or the budget is too slow for the timeout.

Warning
The counters are plain integers the client updates on its own strand. Read them only when no request is in flight, or from code running on that strand; a completion handler bound to another executor can race with other requests.
Returns
The counters, or nullptr if the client is not paced.
