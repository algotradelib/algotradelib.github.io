Detailed Description

One instrument's bars as numeric columns: one row per bar, one column per BarField.

Build one with from_bars(). column() and the named accessors return views into the frame's own storage, without copying.

A field the broker did not report (an open on a day with no trade, an omitted traded value) is missing() in that row, not zero.
