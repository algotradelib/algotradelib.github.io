Detailed Description

The math types and decompositions, implemented with Eigen.

Include math/matrix.hpp rather than this header. Write against the math:: names (math::SeriesView, math::ColPivQr, ...) rather than the Eigen types behind them.

The decompositions are Eigen's own classes under math:: names; use their Eigen interfaces directly:

// One factorization, many right-hand sides; `b` may be a vector or a matrix.
const math::ColPivQr qr(a);
const math::Matrix coefficients = qr.solve(b);
if (qr.rank() < a.cols()) { ... } // the columns were not independent
// LLT for a symmetric positive-definite system, LDLT when it is only semi-definite,
// Svd for the minimum-norm solution, HouseholderQr when pivoting is not needed.
const math::Llt chol(normal);
if (chol.info() == math::SUCCESS) { x = chol.solve(b); }

Matrix::ldlt(), Matrix::colPivHouseholderQr() and the other member forms work too, as does A.fullPivLu().solve(b) for a square system where no structure is known.
