Detailed Description

template<typename Session>
class algotradelib::live::SessionExecutor< Session >

The executor that sends a runner's orders and cancellations through a broker session.

It copies a strategy::PlannedOrder into an OrderRequest (prices and quantities are already on the grid) and classifies a failure with runner::outcome_of. Usually made by bind or bind_journaled.

◆ default_route()

template<typename Session>
Venue algotradelib::live::SessionExecutor< Session >::default_route ( ) const
inlinenoexcept

Returns the venue an order that names none is sent to.

A strategy's orders name no venue, so this is the route of every order a runner plans; an order that names a venue keeps it. The runner writes the route into the order before sending, so the journal and reports name it.

UNSPECIFIED (the default) takes the broker's own default: KRX at KIS, none needed at Toss, and a refusal at Kiwoom, which has no default (give Venue::KRX, Venue::NXT, or Venue::COMBINED for its SOR). At KIS, Venue::COMBINED selects SOR, which a demo account refuses. A route the broker cannot take is refused before any request.

Warning
Prefer Venue::KRX or Venue::NXT to Venue::COMBINED until SOR orders have been seen listed on your account. Journal recovery matches a listed order to the recorded route; if the broker lists a SOR order under the venue where it rests, recovery can conclude the order was never placed, and a restarted runner could send it again. Neither broker's SOR listing has been observed.
Returns
The default route.

Returns the route an order is sent with, for the journal to record before sending (for SOR, COMBINED, not the venue it executes on).

default_route() is applied first; then the broker's traits say where an unspecified venue goes (KRX at KIS). A session whose traits do not say returns the requested route.
