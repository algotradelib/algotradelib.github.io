Detailed Description

An HTTP request for AsyncHttpClient.

A broker adapter builds it and sets group_, the traffic class used for rate limiting and queue priority.

RateLimitGroup algotradelib::network::HttpRequest::group_ {RateLimitGroup::REFERENCE}

The traffic class, for rate limiting and queue priority.

The default, REFERENCE, has the lowest priority, so an unlabelled request never displaces an order. Set TRADING on every order placement, amendment and cancellation, with or without a rate-limit budget: HttpClientOptions::fresh_connection_for_orders_ applies to TRADING requests only.
