Detailed Description

template<typename Client>
class algotradelib::BlockingSession< Client >

A blocking broker client bound to one account, with the same broker operations as BrokerSession, plus accounts().

Every operation returns Result<T>. An operation the broker does not offer does not compile.

Template Parameters
ClientA blocking broker client (BrokerTraits<Client>::blocking is true).

◆ rate_limit_stats()

template<typename Client>
const network::RateLimitStats * algotradelib::BlockingSession< Client >::rate_limit_stats ( ) const
inline

Returns the client's request-pacing counters.

A rising delayed_ on a polling group while TRADING stays undelayed means trading capacity is being kept free; a rising shed_ means the queue was full or the budget is too slow for the timeout. Safe to read between calls.

Returns
The counters, or nullptr if the client is not paced.
