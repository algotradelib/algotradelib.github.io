Detailed Description

How much an OrderIntent trades: a quantity, a notional amount, or a target weight.

The runner converts a notional or a weight into a quantity, using a price and the portfolio. Read the value with the accessor that matches kind(); the others throw.

◆ target_weight()

SizeSpec algotradelib::strategy::SizeSpec::target_weight ( Decimal64 fraction)
inlinestatic

Makes a size as a fraction of portfolio value to hold.

A weight states a holding, not a trade: the runner compares it with what is held and working and trades only the difference, so restating the same weight places nothing. Like a target position, it may withdraw working orders on the instrument (see strategy::weight_target). The target is rounded down to whole lots, so a weight worth less than one share sells the holding to zero; set a TradeTolerance to avoid trading one share each time the price ticks.

Only a buy intent with DAY validity, no trigger and no idempotency key can carry a weight; anything else is refused with RejectReason::UNSUPPORTED_WEIGHT. A weight needs the portfolio value: a backtest supplies it, but a live runner refuses the intent (no_portfolio_value) unless you call Runner::set_portfolio_value.

It is still an order intent, not a TargetPosition: one withheld for the account is dropped, not retained for later; one refused for the market phase is kept, as any intent is.

Parameters
fractionThe fraction of portfolio value, as an exact decimal (for example 0.25); for a computed weight, convert with analytics::to_decimal.
Returns
The size.
