Detailed Description

The compile-time check behind ATL_ASSERT_BROKER(Client).

It calls every operation the client's capabilities claim, through a real session, with a plain callback, a move-only callback and use_future (or directly, for a blocking client), and reads every capability constant. Nothing runs. A missing member, a thunk with the wrong signature or one that copies its completion token, or an unanswered capability fails the build with the compiler's own message. Assert it once, in any one source file (a test is a good place):

ATL_ASSERT_BROKER(my::Client);
ATL_ASSERT_BROKER(my::BlockingClient);

It cannot prove run-time behaviour: that an asynchronous call completes exactly once and on the right executor, or that a claimed capability is true of the broker.
