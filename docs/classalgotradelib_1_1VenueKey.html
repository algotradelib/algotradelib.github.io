Detailed Description

Which venue a commission rate applies to: any venue, a normalized Venue, or a raw code.

The three kinds never match each other: a RAW key never equals a NORMALIZED one even if the text looks the same. A backtest refuses Venue::COMBINED as the venue a fill happened at, since it names consolidated routing (KIS SOR), not where an order matched.
