Detailed Description

Calls a strategy's handlers, skipping the ones it does not declare.

A handler the strategy declares is always called; if its signature does not fit the call (a non-const event, a missing event, a context taken by value), compilation fails here rather than the handler being skipped. A wrapper strategy that forwards to an inner strategy through these functions gets the same check for the inner one.

Calls strategy.on_bar(context, event) if the strategy declares on_bar; otherwise does nothing.

Does not compile for a strategy that declares on_bars: its bars go through bars, so a path that still delivers one BarEvent at a time fails to build instead of skipping the strategy in silence.
