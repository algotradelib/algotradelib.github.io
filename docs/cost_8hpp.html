Detailed Description

Trading costs for a backtest: commission (CommissionModel, CommissionPolicy), slippage (SlippageModel) and how a limit order's fill price is chosen (LimitFillPrice).

Every model charges nothing by default, and the backtest report states what was applied, so a zero-cost run is visible. Sale tax is set on the fill model, NextBarFillModel::with_sell_tax.
