Detailed Description

The examples' Kiwoom credentials: one JSON file per key, or the environment.

Not part of the library. Kiwoom issues one key per account – a Korean-stock account and a US-stock account have a key each – and no request carries an account number: the key is the account. So each key has its own file, named by the environment and a label of your choosing: DIR/kiwoom/demo-kr.json, DIR/kiwoom/demo-us.json, DIR/kiwoom/real-kr.json. --kiwoom-account LABEL picks one (default kr), and KIWOOM_DEMO picks the environment (unset or 1: demo; 0: real). Each file holds appkey, secretkey and demo, as KiwoomConfig::from_json reads them; keep it chmod 600.

The directory is --credentials DIR, else ATL_CREDENTIALS_DIR (kis_credentials::take_directory). With a directory, the environment's KIWOOM_* keys are not read: a directory that lacks the file stops the program rather than falling back, since the environment may hold another account's key. Without one, the examples read KIWOOM_APP_KEY and KIWOOM_SECRET_KEY as before, and a label is refused, because there is nothing for it to select.

A label is the operator's name for an account; the library cannot tell which market a key trades. The Kiwoom adapter calls domestic-stock endpoints only, so a US account's key authenticates and its requests answer as Kiwoom answers them for that account.

algotradelib::network::HttpClientOptions kiwoom_credentials::paced_options ( )

Returns transport options that pace a Kiwoom client at one request a second.

A Kiwoom demo account refuses a second request to the same API within a few milliseconds of the first (1700, "허용된 요청 개수를 초과하였습니다", with the API's id): a quote and a price-limit read are both ka10007, so a loop reading both back to back loses one. Requests to different APIs back to back, and to the same API 300 ms apart, were served (measured 2026-10-07). Kiwoom publishes 1 a second for each API on a demo account, and 5 a second (3 for the balance inquiry kt00018 from 2026-10-29) on a real one. The library paces nothing unless asked (HttpClientOptions::rate_limit_), so these examples ask, at one request a second, inside every published limit.

Returns
The options.
