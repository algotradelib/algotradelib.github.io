Detailed Description

A control file an operator writes to stop a running loop with a given intent.

echo withdraw > /var/run/atl/stop

The first word of the file names the intent; a missing file is normal. Checked once per loop iteration.

Warning
The file is never deleted. A word left in it stops the next process too, from its first iteration (a withdraw or flatten acting on the whole account before anything trades). Remove it before trading again.
