Detailed Description

template<typename Broker>
struct algotradelib::OrderRef< Broker >

A broker's reference to one order, used to amend or cancel it.

The broker is a type parameter, so a reference from one broker cannot be passed to another's session (it does not compile); a broker's asynchronous and blocking clients share one tag. Treat the parts as opaque: store, compare and hash them, but do not parse them.
