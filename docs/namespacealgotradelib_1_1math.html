◆ undefined()

Scalar algotradelib::math::undefined ( )
inline

Returns the value that stands for "the data was there, but the statistic does not exist".

Examples: a z-score over a window with no dispersion, a Sortino ratio over a series that never fell below its target. It differs from missing(), which means there was no data. Both are quiet NaNs, so observed() is false for both and reductions skip both; only is_undefined() tells them apart.

Returns
A quiet NaN with a payload that is_undefined() recognizes.
Warning
Test is_undefined() on a value a function returned (or one copied from a matrix). Arithmetic on it, such as undefined() + 1.0, yields a NaN that may no longer be recognized.
