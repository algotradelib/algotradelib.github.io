Detailed Description

What a journal line says about a run budget's ledger (strategy::RiskLimits::run_budget_).

On a run's PLACE lines it names the run alone; on a CONFIRMED line it also books the fill; on a JournalAction::LEDGER line it is the whole record. A runner without a budget writes none on its own lines, which are then those of a journal from before run budgets; a line it writes to close a restored order of a run keeps that order's run, so a budgeted recovery reads the order as released without a booking.
