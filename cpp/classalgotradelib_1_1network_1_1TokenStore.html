Detailed Description

Where blocking broker clients on one key share its access token, across threads and processes.

Give one to a blocking client (KisBlockingClient, KiwoomBlockingClient, TossBlockingClient). Before a call, a client whose token is missing or within five minutes of its expiry takes the lock of its identity, adopts the stored token if it is valid, and otherwise requests one and publishes it before sending anything else. When the broker refuses the token a call carried, the client discards it from the store, if the store still holds that token.

Each identity (a broker configuration's token_identity()) has its own lock. Call load, publish, discard and remove while holding the object lock returned for that identity. Each function returns filesystem and parse failures, rather than throwing them, as an AUTHENTICATION error with reached_broker_ false, broker code token_store and a fixed message (an allocation can still throw). An implementation must allow calls from several threads at once.
