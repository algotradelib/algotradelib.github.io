Detailed Description

Routes SIGINT and SIGTERM to a StopSource as a quiesce, and ignores SIGHUP where it exists (POSIX); only when install is called.

Both signals mean StopIntent::QUIESCE, never a flatten, since they arrive for routine reasons (a reboot, a deploy, Ctrl+C). SIGHUP is ignored so a dropped SSH session does not stop a process holding positions; Windows has no SIGHUP.

Situation What arrives
tmux send-keys -t sess:0.0 C-c SIGINT to the foreground process
kill -TERM <pid> SIGTERM
host reboot under systemd SIGTERM, then SIGKILL after TimeoutStopSec
docker stop SIGTERM, then SIGKILL after ten seconds
Warning
A supervisor's grace period must exceed one loop iteration plus one request timeout. Otherwise its SIGKILL can kill the process mid-request, leaving an order of unknown outcome that must be reconciled from the broker's order list before trading again.
