Detailed Description

What a measure of a finished replay reads: the replay, its report, and its equity curve's levels and returns as the columns analytics::sharpe, analytics::sortino and analytics::max_drawdown take.

Built by measure_input after the replay, never during it. It borrows the replay: result_ refers to the ReplayResult it was built from, so it must not outlive that result (for Backtester::result(), the engine). Nothing checks this. The deleted overload refuses only a temporary ReplayResult itself; an input built from make_engine().result(), or returned past its result, still dangles.

The levels and returns are copies, because the curve keeps each equity as an exact decimal inside a point.
