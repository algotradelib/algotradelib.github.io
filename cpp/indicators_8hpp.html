Detailed Description

Named technical indicators: the trailing z-score and the relative strength index.

They follow the conventions of rolling.hpp: the result is as long as the input, a value that cannot be computed is missing(), and nothing is reported before the window holds enough observations. Where an indicator has a conventional parameterization (Wilder's smoothing for RSI), its documentation says which one it follows.
