Detailed Description

Alpaca API keys (key id and secret key), paper or live account.

Load with from_env() (ALPACA_KEY, ALPACA_SECRET, ALPACA_DEMO), from_json(filename) or from_json_text(text, origin). Alpaca has no token: both keys go on every request as headers, so nothing is requested or stored before a call. Paper and live keys differ, and a key sent to the other environment's host is refused (HTTP 401) at its first request, so a forgotten setting fails rather than trades.

◆ is_demo_

bool algotradelib::alpaca::AlpacaConfig::is_demo_ = true

Whether to use Alpaca's paper trading host; true unless stated otherwise.

Live trading must be stated: ALPACA_DEMO=0, "demo": false in the credential file, or is_demo_ = false. Live is the same code path as paper and differs only in the trading host; it is supported, but the library's own checks ran on paper only.
