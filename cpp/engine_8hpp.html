Detailed Description

The backtest engine: Backtester replays bars (and quotes) through the same Runner a live session uses.

An order decided on bar n is queued and filled against bar n+1 or later, never the bar it was decided on. Nothing assumes a bar is a day: the same engine replays intraday and daily bars.
