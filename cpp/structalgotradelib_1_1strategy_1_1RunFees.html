Detailed Description

The fees a run budget estimates for an order (RiskLimits::run_fees_).

The same shapes as the backtest's CommissionModel, institution rate and SellTax, stated here because a budget needs them before any fill. They apply per order: the minimum and the rounding apply once to the order's traded value, however many fills make it up. Each charge rounds up to a whole currency unit (an exact zero stays zero), so it is never below a charge truncated to whole units; for a currency with cents the commission and the institution fee, each rounded up, can over-reserve up to two units an order. Per-share fees have no shape here. Default-constructed, it states no fees at all.
