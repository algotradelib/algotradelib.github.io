What one replay produced.

fills, equity, rejected and refused are dicts of columns (pandas.DataFrame(result.fills) makes a table). Times are ns since the epoch (UTC). halted says why the replay stopped early, if it did; the figures then cover only what ran. Figures are NaN where the library has none.

Attributes

Name Type Description
bars int Bars replayed.
fills dict of str to array One row per fill: time, symbol, side (“buy” or “sell”), quantity, price (slippage included), commission, tax (sale tax, KRW) and slippage (the price per share given up to slippage, already in price).
equity dict of str to array The equity curve: time, equity, and period_return, the library’s return since the previous point (rounded to eight places), the series its Sharpe and Sortino are computed from. A return is NaN on the first point, after an unvalued bar, after a point with equity at or below zero, and where the exact arithmetic fails; if equity was at or below zero before the last point, the library reports no Sharpe or Sortino at all.
opening_equity, closing_equity str Equity at the first and last point, as exact decimal text; empty when the curve has no point.
halted str or None Why the replay stopped early, or None.
total_return, max_drawdown float The return over the run and the largest fall from a peak, as fractions (0.05 is 5 %).
sharpe, sortino float Per period of the equity curve (one bar’s interval), not annualized.
annualized_sharpe float sharpe scaled to a year of KRX trading days.
turnover float Everything traded (buys and sells, quantity x price) divided by the opening equity, over the whole run.
commission_paid, tax_paid, slippage_paid float Costs over the run, KRW; NaN where the library cannot state a total.
rejected dict of str to list Targets the runner could not turn into an order: symbol and reason (the library’s name).
refused dict of str to list or array Orders the risk guard refused: symbol and reason (lists; the reason is the library’s name), and, as arrays, the limit exceeded and the value attempted, in the reason’s own unit (shares for quantity_not_sellable), NaN where the reason has none.
unfilled int Orders still waiting when the replay ended.
gaps int Bars that did not follow the bar before them; nothing is interpolated across a gap.
unvalued_bars int Bars at which the equity could not be valued exactly (a total too large for an exact decimal); such a bar has no point in equity. The library’s own figures leave the next period’s return out; a return computed between two exported points would span the missing bar. Check it is 0 before computing measures from equity per period.
lowest_cash float The lowest cash (KRW) an execution left, if an execution took cash below zero; NaN otherwise, which includes a run that started below zero and executed nothing.
aborted int Orders cleared when the replay halted, apart from unfilled.
overdrawn_bars int Input bars that ended with cash below zero (with several symbols, one per symbol’s bar).
unchecked_fill_causality int Decisions to fill an order against a bar that the engine could not check were made before that bar (for example with weekly, monthly or yearly bars stamped at their close). Counted when the order is matched to the bar, before it is priced, so it is not a count of fills.
